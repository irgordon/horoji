# v0.5.0-rc.1 Release Candidate Decision

## Status

Accepted as Release Candidate

## Decision

Horoji v0.5.0-rc.1 is accepted as a release candidate for v1.0.0 review.

This decision does not release v1.0.0 and does not claim final production
readiness. It records that the current repository state is ready for
release-candidate validation from a frozen public surface.

## Scope

This release candidate covers:

- installability from the documented repository setup path
- public CLI usability for the existing small command surface
- schema contract documentation
- release gate and CI alignment
- authoritative ownership coverage
- determinism and repository-locality enforcement
- derived artifact provenance
- committed derived policy enforcement
- operator README guidance

## Non-Scope

This release candidate does not include:

- final v1.0.0 release
- production tag
- public regeneration command
- public invalidation command
- network service
- daemon
- plugin system
- probabilistic retrieval
- reasoning engine behavior
- source-of-truth replacement

## Freeze Boundaries

The following surfaces are frozen for release-candidate review unless a change
is required to fix a release blocker:

- public CLI surface
- governed metadata schema surfaces
- release validation gate
- authoritative and derived trust boundary
- ownership enforcement
- determinism and repository-locality enforcement
- committed derived policy

During RC review, Horoji must not expand architecture, add public CLI commands,
add generators, add invalidation behavior, weaken validators, relax committed
derived policy, or claim final production readiness.
